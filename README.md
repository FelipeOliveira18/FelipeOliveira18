## Sobre mim

Sou estudante de **Ciência da Computação**, com foco em desenvolvimento **Backend**.

Tenho estudado e desenvolvido projetos utilizando principalmente **Java, Spring Boot, APIs REST e MySQL**, buscando transformar o conhecimento teórico da graduação em projetos práticos.

Atualmente, meu foco é evoluir cada vez mais na área de desenvolvimento backend, fortalecendo fundamentos, boas práticas e experiência com desenvolvimento de APIs.
